# my_start

A simple starter project by Aissa Nouacer.

## ⚙️ Getting Started

### Prerequisites
- Node.js (v14+)
- npm or yarn

### Installation
```bash
git clone https://github.com/AissaNouacer/my_start.git
cd my_start
npm install
```
### Run Locally
```
npm run dev
```

###🗂️ Project Structure
```
/my_start
├── backend/        ← server-side code
├── frontend/       ← client-side code
└── README.md
```
